# Kana & Hangeul Wort-Generator

Zwei kleine, eigenständige HTML-Seiten zum Üben des Lesens von japanischen Kana und koreanischem Hangeul. Kein Build, kein Server nötig — einfach die Datei im Browser öffnen.

## Dateien

- **`kana_wort_generator.html`** — Hiragana & Katakana Wort-Generator (Japanisch)
- **`hangeul_wort_generator.html`** — Hangeul Wort-Generator (Koreanisch)

## So funktioniert's

1. Silben bzw. Konsonanten/Vokale auswählen, die du üben willst (gruppiert nach Grundzeichen, Trübungszeichen/angespannte Konsonanten, Kombinationen/zusammengesetzte Vokale).
2. Einstellungen wählen: Schriftart (bei Kana), Anzeige (Original + Umschrift / nur Original / nur Umschrift), Wortlänge und Anzahl der Wörter.
3. "Wörter generieren" klicken und die zufällig erzeugten Übungswörter der Reihe nach durchgehen.

### Kana-Generator (Japanisch)
Kombiniert echte Hiragana-/Katakana-Silben (Moren) zu zufälligen Übungswörtern, mit Romaji-Umschrift.

### Hangeul-Generator (Koreanisch)
Setzt aus ausgewählten Konsonanten (초성) und Vokalen (모음) zufällige Hangeul-Silbenblöcke zusammen (optional mit zufälligem Schlusskonsonant/받침) und zeigt eine vereinfachte Umschrift an.
